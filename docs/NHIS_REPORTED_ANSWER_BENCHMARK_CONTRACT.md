## Complete source frame and honest refusal

The sole fixed Boolean domain is `full_sample_adult_file`, True for every decoded record. No age, sex, proxy or response filter is introduced. All seven answers, including diagnosis unknown, diagnosed type unknown and inconsistent type universe, remain in the denominator. The existing classifier is rerun on only `DIBEV_A` and `DIBTYPE_A` selected tokens, stripping ordinary ASCII outer spaces and mapping blank/single period to its existing missing token. Native missing roles remain separate private aggregates. This is a reader policy, not a newly documented NCHS answer code. The decoder's category is a required consistency cross-check.

The bridge checks the fixed delivery's 24,215 records privately, complete category conservation, and source roles before attempting estimation. Missing or duplicate interpreted household keys or lexical aliases cause whole-method refusal: nothing is collapsed and a household key is not declared a count of unique people. Missing `HHSTAT_A` leaves adult-source status unavailable; positive diabetes answers do not fill that gap. Source record type/year remain enforced by the unchanged decoder. These conservative refusal policies do not establish official exclusions.

All annual design rows must have finite positive native weights and known positive integer nested stratum/PSU labels. A missing, zero or negative weight/design label, a full-design singleton stratum, or unsupported numerical representation refuses the complete calculation. No such row is dropped. Native weights are explicitly rounded to nearest binary64; exact binary representability is not required. Nonfinite conversion, underflow to zero, nonpositive conversion, unsupported compensated total or kernel arithmetic still refuses. Native integer labels stay exact; they are never joined or grouped through floating-point aliases. Full-design grouping preserves zero category contributions.

The seven fixed coordinates follow the existing classifier order. Ratios are dimensionless; full covariance is dimensionless squared. Dependence and the expected partition singularity remain intact. No diagonal-only approximation, clipping, jitter or covariance repair is allowed. The unchanged witness/kernel performs the arithmetic; the bridge strips inherited synthetic/NHANES metadata and builds its own fixed private schema. A future successful original-source calculation must truthfully be described as calculated descriptive ratios, while remaining benchmark-only and scientifically unadmitted.

Probability closure uses `abs(fsum(p)-1) <= 32*binary64_epsilon`. Symmetry and every covariance row/column closure use `64*binary64_epsilon*max_abs_cov`, with exact zero required if all covariance entries are zero. A positive scale whose tolerance underflows to zero is unsupported and refused. All values must be finite, probabilities within [0,1], and diagonal variances nonnegative. These are explicit numerical software checks, not clinical acceptance thresholds or tuning. No repair follows a failed check.

## Private result and technical chronology

The contracted library entry `benchmark_reported_answers(archive, native, *, root)` returns an immutable object with a constant repr, fresh private aggregate accessor, fresh technical envelope accessor, and sanitized failure accessor. It retains no source bytes, native records, household keys, tokens, paths or exception objects. There is no writer, CLI, notebook export or public count/estimate release.

After complete decoding, a method refusal may retain the fixed complete private ledger; ratios/covariance remain unavailable as a whole. Before complete decoding, no ledger is claimed. The public technical envelope contains only fixed coarse stage flags, fixed source/contract/helper provenance, source attribution and five false gates. It omits counts, categories, eligibility reasons, supports, percentages, covariance, df and intervals. Private access is not an anonymity guarantee; callers must not export it. Public release would need a separately reviewed finite disclosure contract.

Stage flags reflect actual control flow. Before decoder entry: projection False/not_attempted. A decoder failure after entry: projection None/possibly_partial. After decoder return: projection True/completed even if preflight later refuses. Before witness entry: estimate False/not_attempted. A witness failure after entry: estimate None/possibly_partial. Once the witness returns, estimate True/completed even if the bridge subsequently rejects its schema or numerical closure. No partial ratio/covariance is returned on failure. Scientific `source_admitted` and all five gates remain False in every branch.
